## 9. D0 P6 PRAGMA 优化执行记录（2026-06-30 同日追加）

**修改对象**：`python/soloforge_ai_society/database/pool.py` `_create_connection` 方法

**修改前**（基线快照）：

| PRAGMA | 值 | 状态 |
| --- | --- | --- |
| `journal_mode` | wal | ✅ |
| `synchronous` | 1 (NORMAL) | ✅ |
| `cache_size` | -64000 (≈62.5MB) | ⚠️ 文档要求 -65536 |
| `mmap_size` | 0 | ❌ 未开 |
| `temp_store` | 0 (DEFAULT) | ❌ 未开 |
| `foreign_keys` | 1 (ON) | ✅ |
| `busy_timeout` | 30000 | ✅ |

**修改后**（P6 baseline）：

| PRAGMA | 值 | 状态 |
| --- | --- | --- |
| `journal_mode` | wal | ✅ 保留 |
| `synchronous` | 1 (NORMAL) | ✅ 保留 |
| `cache_size` | **-65536 (64MB)** | ✅ 统一到文档基线 |
| `mmap_size` | **268435456 (256MB)** | ✅ **新增** |
| `temp_store` | **2 (MEMORY)** | ✅ **新增** |
| `foreign_keys` | 1 (ON) | ✅ 保留 |
| `busy_timeout` | 30000 | ✅ 保留 |

**变更语义**：
- ✅ 零删除：原 5 行 PRAGMA 全部保留
- ✅ 零破坏：原 `synchronous=NORMAL`、`foreign_keys=ON`、`busy_timeout=30000` 全部不动
- ✅ 仅 1 处微调：`cache_size` 从 -64000 → -65536（差 64KB，对运行无影响，与文档统一）
- ✅ 2 处新增：`mmap_size=268435456` + `temp_store=MEMORY`

**性能预期**（文档 P6 收益）：
- 读延迟：~5ms → ~1.7ms（约 3x 加速）
- 写吞吐：~1k QPS → ~2-3k QPS（2-3x 提升）
- 总体收益：mmap 减少 read syscall + MEMORY temp 减少磁盘 swap
