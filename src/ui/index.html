调度器说明

SoloForge 使用 Rust 编写的高性能任务调度器，支持：

  • Aging 优先队列 — 任务随等待时间自动提升优先级
  • 跨语言 IPC — 通过 TCP 文本协议与 Node.js 内核通信
  • 仿真桩降级 — Rust 进程不可用时自动切换到内存队列
