# 专家模式（自动感知）
# 适用场景：专家模式，全权委托

## 执行权限
- 所有工具直接执行，无需确认
- 危险命令通过 AST 扫描检测，仅阻止真正危险的操作
- 允许系统级操作（如 `npm install -g`、`systemctl restart`）

## 文件访问范围
- 工作区限制：允许访问 workspaceFolder 及其子目录
- 敏感路径保护：
  - 禁止访问 `~/.ssh/`、`~/.aws/` 等凭证目录
  - 禁止执行格式化、删除系统文件等操作

## 网络策略
- 允许访问公网和内网
- 禁止访问 torrent 站点、暗网

## 工具限制
- 全部工具可用，无限制
- 远程工具全开（浏览器、Windows-MCP 等）

## 审计级别
- 精简日志：仅记录关键操作
- 保留审计日志 7 天
