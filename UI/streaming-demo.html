Server-Sent Events (SSE) 是一种基于 HTTP 的服务器推送技术， 允许服务器向客户端单向发送事件流。 核心特点： • 基于 HTTP 协议，无需 WebSocket • 文本格式 (text/event-stream) • 内置自动重连机制 • 单向通信：服务端 → 客户端 典型应用场景： - LLM 流式输出 (ChatGPT/Claude 等 AI 产品) - 实时股票行情推送 - 系统日志实时监控
交付结果
SSE 是一种轻量级的实时通信方案，特别适合 AI 对话场景中的流式 token 输出。
